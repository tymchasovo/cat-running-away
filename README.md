# Cat Running Away

Вертикальный браузерный раннер про рыжего кота на утреннем рынке. Свайпы в стороны меняют полосу, свайп вверх позволяет перепрыгнуть ящик. На компьютере работают стрелки и пробел. Прилавки нужно обходить. Метр приносит одно очко, рыбка — десять. Лучший результат хранится в браузере.

[Играть](https://tymchasovo.github.io/cat-running-away/)

Для локального запуска откройте index.html в браузере. Сборка и установка зависимостей не нужны.
