# Cat Running Away

Вертикальный браузерный раннер про рыжего кота на утреннем рынке. Свайпы в стороны меняют полосу. Свайп вверх перепрыгивает ящик, а свайп вниз отправляет кота в короткий подкат под столом. На компьютере работают стрелки и пробел. Прилавки нужно обходить. Метр приносит одно очко, рыбка — десять. Улов за попытку виден во время забега, общий кошелёк — в меню. В лавке доступны красная косынка за 30 рыбок, чёрно-белый и серый коты по 60, вечерняя набережная за 120. Покупки, выбранные вещи, настройки звука и рекорд хранятся в браузере. Музыка и звон рыбок включаются отдельно.

[Играть](https://tymchasovo.github.io/cat-running-away/)

Для локального запуска откройте index.html в браузере. Сборка и установка зависимостей не нужны.
